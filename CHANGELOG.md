# Changelog

## 0.1.0 — Primer lienzo conceptual

- Creación de la presentación web con cámara espacial tipo Prezi.
- Incorporación de diez escenas narrativas.
- Aplicación del nombre definitivo HOSRIA.
- Creación del núcleo de gobernanza de datos.
- Mapa de Propuestas, Reportes requeridos, Comunicaciones, Gestión SEGUN y Gestión MVPD.
- Detalles antes/después para propuestas.
- Flujo conceptual de reportes.
- Distribución segmentada de comunicaciones.
- Resultados organizacionales y cierre.
- Navegación por teclado, scroll, touch, nodos y barra de progreso.
- Pantalla completa y URLs por escena.
- Adaptación responsive y preferencias de movimiento reducido.
- Documentación estratégica, narrativa, visual y técnica.
